# CueDeck + Stream Deck через Bitfocus Companion

Готовая страница кнопок для Stream Deck: таймер с миганием, когда время вышло, «далее» с остатком слайдов, ЭФИР с именем спикера из превью, пуск ролика с остатком времени. Один файл — импортировал, и всё работает.

Файл страницы **`CueDeck.companionconfig`** встроен в CueDeck: **⚙ Настройки** → «Внешнее управление» → **Страница Companion…** → сохранить. (В репозитории он лежит рядом с этим README.)

---

## Что понадобится

| | |
|---|---|
| **CueDeck** | версия с «Внешним управлением» (после 0.6.3) |
| **Bitfocus Companion 5** | бесплатно, [bitfocus.io/companion](https://bitfocus.io/companion) — Mac / Windows / Linux |
| **Stream Deck** | любой: на 15 кнопок видна основная часть, на XL (32) — вся страница. Без Stream Deck можно жать кнопки прямо в Companion или с планшета |
| **Интернет** | один раз, при импорте: Companion сам докачивает модуль «Generic: HTTP Requests». На площадке без сети — импортировать заранее |

> Из России сайт загрузки Companion может не открываться — качать через VPN. Магазин модулей Companion при этом работает без VPN (проверено 24.09.2026).

## Подключение — 4 шага

### 1. Companion: импортировать страницу

0. В CueDeck: кнопка **⚙** внизу окна → «Внешнее управление» → **Страница Companion…** → сохрани файл (по умолчанию на рабочий стол).
1. Открой Companion (в браузере откроется `http://127.0.0.1:8000`).
2. Слева **Import / Export** → **Import configuration** → выбери `CueDeck.companionconfig`.
3. На вкладке **Full Import** оставь галки **Buttons** и **Custom Variables** → нажми **Import Preserving Unselected**.

> ⚠️ Full Import **заменяет** все кнопки и custom-переменные Companion на страницу CueDeck. Если в Companion уже есть твои кнопки — сначала нажми там же **Export Current Configuration** (сохранить копию). Импорт в свободную страницу рядом с чужими — в следующей версии.

После импорта в **Connections** появится подключение **cuedeck** с зелёной галкой. Красное — Companion не смог скачать модуль: **Modules** → найти «Generic: HTTP Requests» → поставить.

### 2. CueDeck: включить внешнее управление

Кнопка **⚙** внизу окна CueDeck (на маке ещё меню CueDeck → «Настройки…») → раздел **Внешнее управление**:

- ☑ **Включить**
- ☑ **Companion: состояние на кнопках**, адрес `127.0.0.1:8000`

Внизу раздела должно гореть зелёным:
`● Работает — 127.0.0.1 · HTTP 9420 · OSC 9421`
`● Companion 127.0.0.1:8000: кнопки получают данные`

### 3. Stream Deck

Воткни Stream Deck — Companion подхватит его сам (**Surfaces**). **Родную программу Elgato Stream Deck закрой**: устройством может владеть только одна программа.

### 4. Проверка

Нажми на деке **ТАЙМЕР** — таймер в CueDeck пошёл, на кнопке тикает время. Готово.

## Что на кнопках

Обычный Stream Deck (15 кнопок) видит левые 5 колонок × 3 ряда. XL видит всё.

| | 1 | 2 | 3 | 4 | 5 | 6 (XL) | 7 (XL) | 8 (XL) |
|---|---|---|---|---|---|---|---|---|
| **ряд 1** | **ТАЙМЕР** старт/пауза, время на кнопке; вышло — мигает красным | ↺ СТАРТ заново | +1 мин | −1 мин | ЗАСТАВКА (красная, когда включена) | таймер 5 мин | таймер 10 мин | таймер 15 мин |
| **ряд 2** | ◀ НАЗАД | **ДАЛЕЕ ▶** «ост N» слайдов; последний — жёлтая | **ЭФИР ▶** + кто в превью | СЛЕД. → превью + кого поставит | **РОЛИК** ▶⏸ + остаток; играет — зелёная | — | — | ← ПРЕД. в превью |
| **ряд 3** | ролик с начала | ЗВУК эфира (красная — выкл) | СПИКЕРУ текст 1 | УБРАТЬ текст (жёлтая, пока висит) | ТОЛЬКО ТАЙМЕР ⛶ | ролик −10 с | ролик +10 с | таймер сброс |
| **ряд 4** (XL) | СПИКЕР 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

- «СПИКЕР N» ставит в превью N-ю запись плейлиста — номера видны на карточках CueDeck, когда включено внешнее управление.
- «СПИКЕРУ текст 1» — первый пресет сообщения на суфлёр (текст меняется в CueDeck правым кликом по кнопке пресета).
- Команды эфира идут **сразу в зал**, как с кликера.
- Закрыл CueDeck или он упал — через 10 секунд на кнопке таймера «нет связи», а не застывшее время.

## Своя кнопка

Любая кнопка страницы — это две вещи: **что она шлёт** в CueDeck и **что показывает**.

**Проще всего — скопировать похожую.** Companion → **Buttons** → выделить кнопку → `Cmd+C` → пустая ячейка → `Cmd+V` → щёлкнуть по копии и поменять:

| Вкладка редактора | Что там | Пример |
|---|---|---|
| **Step 1** → Press actions | действие `cuedeck: GET`, поле **URI** — путь команды CueDeck | `timer/set/20` — таймер на 20 минут; `playlist/air/5` — пятый спикер сразу в эфир; `message/text/Вопросы из зала` |
| **Style** → Text | подпись; живое значение — через переменную | `ОСТАЛОСЬ $(custom:cuedeck_slides_left)` |
| **Style** → Background → Color | цвет фона; кнопка «√x» справа переключает поле в выражение | `$(custom:cuedeck_blackout) == '1' ? '#b3261e' : '#000000'` |

**Где взять:**
- **все команды** — CueDeck → **⚙ Настройки** → «Внешнее управление» → **Список команд…** (там же кнопка «копировать»; в Companion вставлять только хвост после `/api/`, например `timer/set/20`);
- **все переменные** — Companion → **Variables** → **Custom Variables** (всё, что начинается на `cuedeck_`, с описанием).

**Кнопка с нуля:** пустая ячейка → **Regular button** → Step 1 → **+ Add action** → набрать `cuedeck` → **GET** → в URI путь команды.

**Несколько команд одной кнопкой** — несколько действий подряд в Press actions: например `playlist/next`, потом `take` — «следующий спикер сразу в зал».

> ⚠️ Повторный импорт страницы CueDeck **затрёт** твои правки на ней. Свои кнопки держи на **другой странице** Companion (Buttons → стрелка вправо у номера страницы) или перед импортом сделай Export.

## Если Companion на другом компьютере

| Где | Что поменять |
|---|---|
| CueDeck | ☑ **Из сети**; адрес Companion — `IP-компьютера-с-Companion:8000` |
| Companion | **Connections** → cuedeck → **Base URL** = `http://IP-компьютера-с-CueDeck:9420/api/` |

Часы обоих компьютеров должны совпадать (обычно синхронизированы сами), иначе таймер на кнопке покажет «нет связи».

## Планшет вместо Stream Deck

Companion показывает те же кнопки в браузере: меню **Interactive Buttons** или с планшета в той же сети — `http://IP-компьютера-с-Companion:8000`.

## Не работает

| Симптом | Что делать |
|---|---|
| В CueDeck «⚠ Companion не отвечает» | Companion не запущен или другой адрес/порт (Companion → Settings) |
| «⚠ В Companion нет переменной cuedeck_…» | Страницу не импортировали или импортировали без галки **Custom Variables** — шаг 1 |
| Время на кнопках есть, а нажатия не работают | Connections → cuedeck красное (нет модуля) или неверный Base URL |
| Stream Deck не видно в Companion | Закрыть родную программу Elgato; Surfaces → Rescan |

## Для разработчика

Файл собирается скриптом из той же таблицы переменных, что использует CueDeck:

```bash
npx vite-node companion/build.ts
```

Раскладка и подписи — `companion/build.ts`; переменные — `src/main/remote/companion-vars.ts`; отправка из CueDeck — `src/main/remote/companion-push.ts`. Формат — экспорт Companion 5.0.6 (JSON, version 12). В Companion 5 кегль текста — **% от высоты элемента**: подписи 25–36, иначе «Shrink to fit» режет слова пополам.
