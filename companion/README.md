# CueDeck + Bitfocus Companion

Кнопки CueDeck можно вывести на Stream Deck: листать слайды, запускать видео и управлять таймерами. На кнопках отображаются время и состояние эфира.

Для настройки понадобится [Bitfocus Companion 5](https://bitfocus.io/companion). Сначала подключим его на том же компьютере, где работает CueDeck.

## Готовые кнопки

### 1. Сохраните файл из CueDeck

Откройте «Настройки → Внешнее управление» и нажмите «Экспорт страницы…». Сохраните файл `CueDeck.companionconfig`.

В CueDeck 0.13 эта кнопка называется «Страница Companion…».

### 2. Импортируйте файл в Companion

Откройте Companion. Перейдите в Import / Export → Import configuration и выберите сохранённый файл. Импортируйте кнопки и Custom Variables: через них на кнопки передаются время и номера слайдов.

Если в Companion уже есть ваша раскладка, сначала сохраните её через Export Current Configuration. Полный импорт заменяет существующие кнопки и переменные.

В Connections появится подключение `cuedeck`. Оно должно быть зелёным. Если Companion просит установить Generic: HTTP Requests, установите этот модуль.

### 3. Включите управление в CueDeck

В «Настройки → Внешнее управление» включите:

- «Включить»;
- «Передавать состояние в Companion».

Адрес Companion на этом же компьютере: `127.0.0.1:8000`. В CueDeck 0.13 вторая галка называется «Companion: состояние на кнопках».

### 4. Проверьте кнопки

На странице CueDeck в Companion нажмите «ТАЙМЕР». Таймер суфлёра должен запуститься, а время на кнопке начать меняться.

Подключите Stream Deck и откройте Surfaces в Companion. Закройте приложение Elgato Stream Deck, чтобы оно освободило устройство.

Раскладка рассчитана на Stream Deck XL. Для меньшей деки скопируйте нужные кнопки на свою страницу. Управлять ими можно и мышью в Companion, без Stream Deck.

## Если нужны пресеты

Модуль CueDeck добавляет кнопки в Presets. Их можно перетаскивать на свою раскладку.

1. [Скачайте модуль CueDeck 0.4.1](https://github.com/ttpa3dhuk/CueDeck/releases/download/v0.13.0/cuedeck-cuedeck-0.4.1.tgz). Распаковывать файл не нужно.
2. В Companion откройте Modules → Import module package и выберите скачанный `.tgz`.
3. В Connections нажмите Add Connection и добавьте CueDeck. Выберите Module Version 0.4.1.
4. Укажите адрес CueDeck `127.0.0.1` и HTTP-порт `9420`. В CueDeck должно быть включено внешнее управление.
5. Откройте Presets → CueDeck и перетащите нужные кнопки на страницу.

При работе через модуль готовый файл страниц импортировать не требуется.

## Какие кнопки выбрать

«Далее» и «Назад» листают презентацию в эфире. Кнопки превью выбирают материал для подготовки, TAKE выводит его в зал.

Таймер суфлёра и таймер зала управляются отдельно. Для зала используйте страницу или пресеты «Таймер зала».

Чтобы изменить время или номер слайда у кнопки, откройте [настройку своих кнопок](BUTTONS.md).

## Если программы на разных компьютерах

Оба компьютера должны быть в одной сети. В CueDeck включите «Из сети».

При использовании готовых страниц укажите в CueDeck адрес компьютера с Companion и порт `8000`. В Companion откройте Connections → cuedeck и замените Base URL на `http://АДРЕС-CUEDECK:9420/api/`.

Для модуля CueDeck адрес компьютера меняется в настройках самого подключения. Если включена защита управления из сети, настройте [доступ по ключу](NETWORK-ACCESS.md).

## Если не заработало

| Что происходит | Что проверить |
| --- | --- |
| Кнопки не управляют CueDeck | В CueDeck включено внешнее управление; подключение в Connections зелёное; адрес и порт совпадают |
| Кнопки работают, но время не меняется | Для готовых страниц включите передачу состояния в Companion и проверьте импорт Custom Variables |
| Companion не видит Stream Deck | Закройте приложение Elgato Stream Deck, затем откройте Surfaces и нажмите Rescan |

Сборка файлов страниц описана [отдельно для разработчиков](DEVELOPMENT.md).
