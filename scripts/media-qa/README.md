# Проверка медиаформатов

На мероприятие могут принести файл с неподходящим кодеком, даже если заранее просили MP4/H.264. Эти скрипты готовят материалы и проверяют, что браузер действительно выдаёт картинку и звук.

## Материалы

Генератор рассчитан на Mac с FFmpeg и ffprobe. Нужны VideoToolbox, libvpx-vp9, libsvtav1, libmp3lame и libopus в сборке FFmpeg.

```sh
python3 scripts/media-qa/fixtures.py generated/media-fixtures
```

В папке появятся видео и звуковые файлы с движущимся testsrc2 и двумя тонами 440/880 Гц. Манифест хранит команды, SHA256 и параметры ffprobe. Повторный запуск использует готовые файлы с прежним рецептом и хешем. Для другого рецепта нужна новая папка.

```sh
python3 scripts/media-qa/fixtures.py generated/media-one --only h264-4k60.mp4
```

## Проба декодера

[decoder-probe.js](decoder-probe.js) выполняется через CDP в тестовом renderer Electron. Функция `probeMedia(url, seconds, audio)` принимает URL материала, записывает представленные видеокадры, ошибки, перемотку и сигнал двух звуковых каналов. При измерении аудио физический выход графа имеет нулевое усиление.

URL должен быть доступен этому renderer с корректным CORS. Обработчик тестовых ресурсов должен отдавать только явно выбранные материалы. Нужен положительный контроль H.264: ошибка доставки файла не должна превращаться в вывод о неподдерживаемом кодеке.

## Границы

Успешный `play()` не доказывает наличие видео: браузер может принять только звуковую дорожку. Проверять картинку, звук и импорт CueDeck отдельно. Короткая проба не задаёт минимальные требования к железу и не заменяет проверку физического звука, нескольких дисплеев и длительного воспроизведения.
