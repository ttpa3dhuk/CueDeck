# Если CueDeck не запускается на Windows

[English](windows.md)

CueDeck пока не подписан сертификатом Microsoft, поэтому Windows иногда его не пускает. Ниже — что делать, по порядку.

## 1. Распакуй архив полностью

Из zip CueDeck не запустится. Правый клик по архиву → **Извлечь все…** → запускай `CueDeck.exe` из распакованной папки.

Чтобы было меньше предупреждений, до распаковки: правый клик по zip → **Свойства** → внизу галка **Разблокировать** → OK.

## 2. Синее окно «Система Windows защитила ваш компьютер»

Это SmartScreen. Нажми **Подробнее** → **Выполнить в любом случае**. Спрашивает один раз.

## 3. «Это приложение заблокировано», кнопки «Выполнить» нет

Значит, включён **Smart App Control** (обычно на свежеустановленной Windows 11). Его нужно выключить:

Пуск → **Безопасность Windows** → **Управление приложениями/браузером** → **Параметры интеллектуального управления приложениями** → **Выкл**.

> ⚠️ Обратно Smart App Control включается только переустановкой Windows. Антивирус и брандмауэр при этом продолжают работать.

### Окно «Безопасность Windows» не открывается или сразу закрывается

Тогда то же самое — командой. Открой PowerShell **от имени администратора** (Пуск → правый клик по «Терминал» или «PowerShell» → **Запуск от имени администратора**), вставь строку и нажми Enter:

```
reg add HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy /v VerifiedAndReputablePolicyState /t REG_DWORD /d 0 /f; citool -r
```

Если после этого CueDeck всё равно не запускается — перезагрузи компьютер.

## 4. Выходы OMT не видны в vMix / OBS

При первом включении выходов OMT Windows спросит доступ к сети: поставь галку **Частные сети** → **Разрешить доступ**. Если окно закрыли без ответа, Windows запомнит запрет. Тогда в PowerShell от имени администратора:

```
Get-NetFirewallRule -DisplayName CueDeck | Set-NetFirewallRule -Action Allow
```

## Не помогло

В CueDeck: **Help → Сообщить о проблеме…** → на рабочем столе появится zip, пришли его автору.
