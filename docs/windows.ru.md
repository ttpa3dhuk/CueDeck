# Если CueDeck не запускается на Windows

[English](windows.md)

CueDeck пока не подписан сертификатом Microsoft, поэтому Windows иногда его не пускает. Подпись стоит денег, мы её пока не покупали. Ниже по шагам, что делать.

## 1. Распакуй архив полностью

Прямо из zip CueDeck не запустится. Правый клик по архиву, «Извлечь все…», и запускай `CueDeck.exe` из распакованной папки.

Предупреждений будет меньше, если до распаковки открыть свойства архива (правый клик, «Свойства») и внизу поставить галку «Разблокировать».

## 2. Синее окно «Система Windows защитила ваш компьютер»

Это SmartScreen. Нажми «Подробнее», потом «Выполнить в любом случае». Он спрашивает один раз.

## 3. «Это приложение заблокировано», а кнопки «Выполнить» нет

Значит, включён Smart App Control. Обычно он бывает на свежеустановленной Windows 11. Его нужно выключить: Пуск, «Безопасность Windows», «Управление приложениями/браузером», «Параметры интеллектуального управления приложениями», «Выкл».

Обратно Smart App Control включается только переустановкой Windows. Антивирус и брандмауэр при этом продолжают работать.

### Окно «Безопасность Windows» не открывается или сразу закрывается

У нас на одном компьютере так и было. Тогда то же самое делается командой. Открой PowerShell от имени администратора (Пуск, правый клик по «Терминал» или «PowerShell», «Запуск от имени администратора»), вставь строку и нажми Enter:

```
reg add HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy /v VerifiedAndReputablePolicyState /t REG_DWORD /d 0 /f; citool -r
```

Если CueDeck после этого всё равно не запускается, перезагрузи компьютер.

## 4. vMix или OBS не видят выходы OMT

Когда включаешь выходы OMT в первый раз, Windows спрашивает доступ к сети. Поставь галку «Частные сети» и нажми «Разрешить доступ». Если окно закрыли без ответа, Windows запоминает запрет, и тогда помогает команда в PowerShell от имени администратора:

```
Get-NetFirewallRule -DisplayName CueDeck | Set-NetFirewallRule -Action Allow
```

## Не помогло

В CueDeck открой меню Help, «Сообщить о проблеме…». На рабочем столе появится zip, пришли его автору или приложи к [issue](https://github.com/ttpa3dhuk/CueDeck/issues/new/choose).
