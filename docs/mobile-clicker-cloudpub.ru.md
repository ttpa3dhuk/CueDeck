# Мобильный кликер и CLOUDPUB

CueDeck содержит собственный HTTP-сервер кликера. CLOUDPUB публикует отдельный адрес `http://127.0.0.1:ПОРТ`, указанный в настройках.

## Подключение и пользователи

1. Установите CLOUDPUB, войдите в аккаунт и оставьте графический клиент работающим.
2. Откройте **Настройки → Кликер → Онлайн кликер**, нажмите **Подключить CLOUDPUB автоматически** и дождитесь проверки внешнего доступа. Для нестандартной установки можно выбрать программу вручную.
3. Создайте ссылку и QR-код для всех либо выбранных PDF/PPTX.
4. Новые заявки появляются над нижней кнопкой онлайн-кликера: имя, короткий код, презентации и **Одобрить / Отклонить**. Одобрение персональной ссылки сохраняет её ограничения. Для общей ссылки права выбирает оператор прямо в карточке.

В открытом гостевом режиме посетители общей ссылки допускаются автоматически с выбранными правами. Индивидуальная блокировка сохраняется при обновлении гостевой политики. Закрытие гостевого доступа блокирует гостевые команды. Полный список пользователей и изменение прав доступны в настройках.

Кнопка **Онлайн кликер** ставит управление на паузу: страница остаётся доступна, кнопки телефона серые, команды отвергаются сервером. Если разрешённая презентация не открыта, телефон показывает **«Ваша презентация не открыта»**.

Настройки глобального кликера видны сразу, онлайн-настройки свёрнуты. Нижняя кнопка глобального кликера показывает состояние и мигает красным при ошибке включения; при запрете анимаций используется постоянный красный сигнал.

Для ручной публикации укажите публичный HTTPS origin без пути и параметров. Публикуйте только адрес кликера, а не сервер полного внешнего управления CueDeck.

## Адрес и платформы

Адрес имеет вид `cuedeck-<код ПК>.cloudpub.ru`. Код — сокращённый SHA-256 аппаратного UUID: SMBIOS UUID в Windows, IOPlatformUUID в macOS. Windows использует MachineGuid, если аппаратный UUID недоступен. Исходный идентификатор не сохраняется и не публикуется. Перезагрузка не меняет код; замена оборудования, клонирование UUID виртуальной машины или переустановка Windows при использовании MachineGuid могут его изменить. Код адреса не является паролем.

Повторное подключение использует сохранённый GUID публикации. При утрате локальной записи CueDeck ищет точное совпадение имени и адреса; смена локального порта обновляет ту же публикацию. Переход со старого адреса требует повторной передачи ссылок и QR-кодов.

Поиск CLOUDPUB поддерживает стандартную установку Windows, macOS `.app`, Homebrew и PATH. Конфигурация macOS ищется в `~/Library/Application Support/cloudpub/client.toml` и совместимом `~/.config/cloudpub/client.toml`.

## Доступ и нагрузка

- HTTP-интерфейс предоставляет страницу, запрос допуска, состояние и команды вперёд/назад. Файловые, системные и административные операции через него не доступны.
- Права на презентацию, блокировка и пауза повторно проверяются перед командой. Основной процесс дополнительно проверяет актуальность презентации, состояние управления и интервал команд.
- HTTP работает в отдельном Electron utility process с ограничением heap. Это отделяет сетевую обработку от основного цикла приложения, но не создаёт отдельную песочницу ОС.
- Ключи и права сохраняются через Electron safeStorage в локальном профиле и не включаются в экспорт проекта. Токен клиента CLOUDPUB передаётся только официальному HTTPS API без переадресаций; CueDeck его не сохраняет.
- CLI запускается без shell, с лимитами времени и вывода. Перед изменением/остановкой публикации проверяются GUID и локальный адрес; массовые операции над публикациями не используются.

| Ограничение | Значение |
| --- | --- |
| TCP-соединения | 32 на вход |
| Заголовки / тело команды | 8 КиБ / 2 КиБ |
| Таймаут запроса / keep-alive | 5 с / 1 с |
| HTTP-запросы | 80/с, burst 120 |
| На TCP-адрес | 60/с, burst 100; forwarded IP не считается доверенным |
| На ссылку / пользователя | 12/с / 5/с |
| Команды | 4/с, одна незавершённая команда, без очереди |
| Ссылки / пользователи | 64 / 128, до 16 на ссылку |
| Гостевые заявки | 0,5/с, burst 4; до 16 ожидающих и 64 сессий |

Ограничения защищают обработчики приложения, но не гарантируют доступность интернет-канала, ОС или инфраструктуры туннеля при DDoS.

## Проверки

```sh
npm run typecheck
npm run test:mobile-clicker -- --maxWorkers=1
npm run test:mobile-clicker:runtime
```

Живые сценарии требуют установленного CLOUDPUB с выполненным входом. Они создают временную публикацию и удаляют только её:

```sh
node scripts/cloudpub-live-qa.cjs --live
node scripts/mobile-clicker-ui-qa.cjs --live
```

Worker упакованной сборки: `node scripts/mobile-clicker-electron-qa.cjs --packaged=<путь-к-папке-приложения>`.

На Windows проверены реальный UUID, Electron, HTTPS, допуск/отказ, ограничения презентаций, пауза и нагрузка. macOS покрыта тестами путей и IOPlatformUUID; запуск и сборка на настоящем Mac требуют отдельной проверки.

Протокол интеграции: [CLI CLOUDPUB](https://cloudpub.ru/docs/cli), [схема API](https://cloudpub.ru/api/schema/).
