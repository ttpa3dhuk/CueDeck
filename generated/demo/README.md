# Демо-комплект для видео про CueDeck

Материалы под запись ролика. **Всё вымышленное** — реальных клиентских
презентаций здесь нет и быть не должно.

Презентации написаны по теме самой программы: переключая файлы в плейлисте,
идёшь по своему рассказу. Форматы намеренно разные — в кадре видно, что
CueDeck открывает их одинаково.

## Порядок в плейлисте

| Файл | Формат | О чём |
| ---- | ------ | ----- |
| `01_Проблема.pdf` | PDF, 8 стр. | Зачем всё затевалось: боль оператора на площадке |
| `02_Три-окна.pptx` | PPTX, 8 слайдов | Как устроен показ. **На слайде 3 вшито видео** |
| `03_Что-умеет_1…5.jpg` | JPG, 5 картинок | Плейлист, таймеры, живой вход, заставка |
| `04_Ролик-о-программе.mp4` | MP4, 21 с | Видеофайл как элемент плейлиста |
| `_заставка.png` | PNG | Ключевой визуал между выступлениями |
| `_отбивка.mp4` | MP4, 15 с | Заставка в движении, если нужен фон |

## Что чем демонстрируется

- **Разные форматы в одной очереди** — первые четыре файла.
- **Видео внутри PPTX** — слайд 3 колоды «Три окна» (`ppt/media/media1.mp4`).
  Проверено структурно: ссылка `a:videoFile` на месте, LibreOffice
  конвертирует деку в 8 страниц. Как это выглядит в оверлее — смотреть в самой
  программе.
- **Видеофайл в плейлисте** — `04_Ролик-о-программе.mp4`, дорожка AAC есть,
  можно проверять маршрутизацию звука и предпрослушку.
- **Заставка** — `_заставка.png` в ключевой визуал.

Звук в ролике — служебный тихий пад, чтобы дорожка была не пустой. Под публикацию
менять на нормальную музыку.

## Пересобрать

```bash
# python-pptx нужен в окружении
python3 build_demo.py            # → PPTX
soffice --headless --convert-to pdf --outdir . 01_Проблема.pptx
pdftoppm -jpeg -r 144 03_Что-умеет.pdf 03_Что-умеет   # → JPG 1920×1080
```

Текст слайдов правится прямо в `build_demo.py` — он же держит стиль
(цвета, отступы, гашение теней от LibreOffice).
