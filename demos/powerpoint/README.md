# CueDeck: демонстрация и повторные проверки PPTX

Один файл [CueDeck-demo.pptx](CueDeck-demo.pptx) для показа возможностей и проверки новых сборок. Внутри 20 исходных слайдов. После разворачивания появлений по клику CueDeck показывает 24 страницы. Тексты и заметки объясняют, что должно произойти.

Все картинки, GIF и ролики созданы для этого примера. Переписки и презентаций коллег в файле нет. Наличие сценария не означает, что он прошёл приёмку.

| Слайды PPTX | Сценарий | Что проверить |
| --- | --- | --- |
| 1–2 | Начало, заметки и таймер | Текст на суфлёре, сообщения спикеру, таймер материала |
| 3–4 | Без перехода и Fade | Отдельно переход из PPTX и ручное переопределение CueDeck. Обычный Fade читается; действует ограничение показа 400 мс |
| 5 | Три появления по клику | Последовательность и обратное листание |
| 6–9 | Видео A → видео B → видео A → статика | Начало с первого кадра, отсутствие чёрного промаргивания, прекращение старого звука. Регрессия перехода после встроенного видео |
| 10 | Видео по команде | Само не запускается; в CueDeck используется видеотранспорт |
| 11 | Повторяющийся футаж | Несколько циклов при свёрнутом операторе; отдельная проверка фонового воспроизведения |
| 12–14 | GIF, прозрачность, два GIF | Кадры меняются, фон просвечивает, нет статичного первого кадра под анимацией |
| 15 | GIF появляется по клику | До клика скрыт, после клика движется |
| 16 | GIF и видео | Оба видны; пауза видео не останавливает GIF |
| 17, 20 | Возврат к статике, повтор | GIF убран со слайда; возврат и повторное открытие работают |

## Пересобрать пример

Нужны Node.js, Python с Pillow, ffmpeg и pptxgenjs. Зависимость генератора ставится отдельно от приложения:

```sh
npm install --prefix /tmp/cuedeck-demo-tools pptxgenjs@4.0.1
python3 scripts/demo-pptx/media.py
node scripts/demo-pptx/build.cjs
python3 scripts/demo-pptx/timing.py
```

Команды выполняются из корня репозитория. [Генератор](../../scripts/demo-pptx/build.cjs) задаёт слайды, [timing.py](../../scripts/demo-pptx/timing.py) добавляет нативные времена запуска, клики и переход, [media.py](../../scripts/demo-pptx/media.py) создаёт синтетические медиа. Сначала создаётся обычный файл PPTX, затем добавляются временные параметры, потому что библиотека генерации не задаёт их полностью.

## Границы текущей проверки

Схема OOXML и статическая конвертация LibreOffice проверены. Это не заменяет открытие в настоящем PowerPoint и живой прогон CueDeck на обеих ОС. Нельзя объявлять отсутствие чёрных кадров по одним метаданным.

Текущая реализация GIF рассчитана на отдельные прямоугольные изображения. Повороты, отражения и координаты вложенных групп пока остаются статичными. Если перед GIF есть перекрывающая фигура, сохраняется статичная картинка, чтобы не закрыть её анимацией.
